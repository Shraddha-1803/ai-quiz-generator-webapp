# 🤖 AI Quiz Generator Web App

An AI-powered **Quiz Generator Web App** built with Flask and Groq API that allows users to create and take quizzes on different topics with automatically generated questions.

The application provides user authentication, AI-generated quizzes, timed questions, instant feedback, progress tracking, and score calculation in an interactive web interface.

# ⚙️ Installation

## 1. Clone the Repository

Open your terminal and run:
```
git clone https://github.com/Shraddha-1803/ai-quiz-generator-webapp.git
```
Navigate to the project folder:
```
cd ai-quiz-generator-webapp
```

## 2. Backend Setup

Create a virtual environment:
```
python -m venv venv
```
Activate the virtual environment.
### Windows
```
venv\Scripts\activate
```
### macOS / Linux
```
source venv/bin/activate
```
Install the required dependencies:
```
pip install -r requirements.txt
```

## 3. Environment Configuration

Create a ```.env``` file in the project root and add your Groq API key:
```
GROQ_API_KEY=your_groq_api_key
```

## 4. Run the Application

Start the Flask server:
```
python app.py
```
Open the application in your browser:
```
http://localhost:5000
```
